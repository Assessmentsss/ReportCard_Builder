FLNBaseline dashboard builder

Turn a baseline sheet into a district dashboard

Upload the cleaned assessment Excel for any district. The builder reads every school and child, links the blocks to the district map, and saves a ready-to-share report card dashboard as a single HTML file. Nothing is uploaded anywhere — it all runs in this browser.

The Kobo export with District, Block, Cluster, School, Roll Number, the task columns and the Lit/Num level columns.

    Gazette spellings are filled in where known. Edit any name; the second name appears in brackets and also works in search.

    Link the blocks to the map

    Upload the district map image (the colour block map with a dark district outline). The builder finds each block on it; you tell it which block is which. Save the map setup once and reuse it next time.

    Click an area on the map, then pick its block. Red areas aren't linked yet.

      3

      Create the dashboard

      Saves one HTML file with the map, school list, school-wise and student-wise report cards and PDF downloads — the same layout as the Nuapada and Baragada dashboards.

        Levels come from the sheet's Lit/Num level columns. If those are missing, a child scoring 80% or more on a competency is Phala, 60–79% Phula and below 60% Kadha. In the sheet a 1 against a question means incorrect and 0 means correct; "All correct" and "All incorrect" flags apply to every question in that task.
